# Orientações para continuidade

- Este projeto usa Unity **6000.4.3f1** e a constituição em `.specify/memory/constitution.md`.
- Consulte `README.md` e `specs/001-prototipo-lago/tasks.md` antes de alterar o projeto.
- Implemente somente a task ou o intervalo explicitamente solicitado pelo usuário. Na ausência
  de um intervalo, execute uma task por vez, valide, atualize seu checkbox e pare para revisão
  e publicação. Não execute todas as tarefas em uma única solicitação genérica.
- T001–T021 estão concluídas neste snapshot. T022 em diante continuam pendentes mesmo quando
  já houver scripts parcialmente escritos. Revise esses scripts antes de concluir a task.
- Preserve os arquivos `.meta`; use Unity para gerar/atualizar cenas e assets serializados.
- Não versione caches, instalações, credenciais, logs ou resultados regeneráveis dos testes.
- Execute testes proporcionais à alteração. Não declare aceite de gameplay, plataforma ou
  desempenho com base apenas em testes de regras.
